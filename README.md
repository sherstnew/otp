# ОТП Мания

Локальный React-прототип системы признания сотрудников: коины, ручной рейтинг и магазин. Данные вымышлены, реальные платежи и доставка отсутствуют.

Кабинет рейтинга: таблица мест и баллов внутри групп по подразделению и роли, личная история за всё время и 12 месяцев, заявки с проверкой, программы развития, благодарности и журнал исправлений. [Описание и сценарий проверки](docs/rating-implementation.md).

Обновление 31.10: тарифные начисления коинов по подтверждённым событиям, персональные лимиты и потолок выпуска. [Разбор новых сообщений, файлов и Google-документов](docs/review-2026-10-31.md).

Правки 01.11: чёрное выделение вкладок, собственные селекты, команды и профили коллег, истории инициатив и исправление подачи по прежним достижениям. [Подробности и границы новых идей](docs/review-2026-11-01.md).

## Запуск

```sh
npm install
npm run dev
```

Открыть адрес Vite. `npm run build` проверяет TypeScript и собирает `dist/`, `npm test` проверяет операции начисления, покупки, права и хранение. `npm run preview` запускает собранную версию.

## Docker

```sh
docker build -t otp-mania .
docker run --rm -p 8080:80 otp-mania
```

Открыть http://localhost:8080. Многоэтапная сборка собирает приложение в Node.js, а nginx раздаёт только готовые файлы. Прямые переходы на `/rating`, `/shop` и `/ui-kit` поддерживаются. Данные по-прежнему сохраняются в браузере; Docker volume не требуется.

## Сценарий показа

1. Через «Сменить профиль» выбрать руководителя Михаила Соколова.
2. Александра подаёт достижение в «Рейтинг» → «Добавить достижение»; Михаил рассматривает его во входящих «Управления», указывает баллы и обоснование.
3. Переключиться на Александру, открыть таблицу рейтинга, сменить период, посмотреть личную историю и команду.
4. В магазине выбрать худи за 3 500 коинов, подтвердить покупку.
5. Проверить заказ, новый баланс и неизменный рейтинг. Перезагрузить страницу.
6. Через «Сменить профиль» выбрать HR Анну Волкову и показать начисления для всех подразделений.
7. В «Управлении» открыть «Коины», выбрать сотрудника и посещение сообщества. Указать уникальный ID, дату события текущего года и обоснование, подтвердить проверку. Начислится 1 000 коинов. Повторная оплата этого события с другим ID операции отклоняется; максимум четыре посещения на сотрудника в год.

Роли переключаются для демонстрации и не являются защищённой авторизацией. Данные хранятся в localStorage одного браузера, ключ `otp-mania-v1`; между браузерами не синхронизируются. Внизу страницы есть сброс с подтверждением. При повреждённом формате сохранения восстанавливается исходное демо. При запрете записи показывается предупреждение.
