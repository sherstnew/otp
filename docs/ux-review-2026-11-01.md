# Проверка ясности интерфейса

## Направление

Сохраняем фирменный язык ОТП: лайм `#C1FF05` для основного действия, фиолетовый `#9E6FC3` для признания, голубой `#C8E1FC` для объяснений, белый `#FFFFFF` для содержимого, серый `#F3F4F6` для фона, текст `#222222`. Используем существующие токены и Onest. Новая типографическая или иконочная система не вводится.

Структура раздела: название → основное действие → одна строка вкладок → ожидаемое содержимое. В рейтинге важнее таблица, в магазине — каталог, в истории — записи. Создание новых записей открывается отдельным модальным действием.

```text
Рейтинг
Добавить достижение
Рейтинг | История | Команда | Программы | Инициативы | Спасибо | Заявки
Мои баллы и место · группа / период / поиск
Место   Сотрудник                  Баллы
1       Иван Лебедев               840
2       Александра Морозова · вы   780
2       Мария Орлова               780
```

Лайм остаётся акцентом для действия и мягкого выделения своей строки. Чёрная подложка обозначает выбранную вкладку. Дополнительная навигация, рекламный блок перед каталогом и повторные большие сводки убраны.

## Найденные несоответствия и исправления

| Было | Стало |
| --- | --- |
| «Рейтинг» открывал обзор развития, таблица была спрятана в команде | Первый экран — места и баллы, своя строка выделена, видны личные баллы и место |
| Суммы и роли можно было неверно воспринимать как общебанковский рейтинг | Выбор группы по подразделению и роли, отдельные группы руководителей, специалистов и HR |
| Поиск мог восприниматься как новый расчёт мест | Места вычисляются до поиска; равные баллы дают одно место |
| Большая личная сводка повторялась на каждой вкладке | Полная сводка осталась в истории рейтинга, на первом экране компактная личная строка |
| «Вся история» возвращала в общий обзор | Открывает непосредственно историю баллов |
| «Мои достижения» фактически показывали и благодарности | Вкладка называется «История рейтинга»; заявки на достижения имеют отдельное название |
| «Возможности» скрывали конкретное назначение раздела | «Программы развития», рядом показываются поданные заявки на программы |
| Форма программы появлялась внизу длинной страницы | Открывается в модальном окне выбранной программы |
| Форма отправки «Спасибо» заслоняла историю | В разделе сначала история и понятное пустое состояние, новая благодарность — модалка |
| У HR «Моя команда» означала каталог всех подразделений | В рабочем месте HR вкладка называется «Команды» |
| «Моя Мания» была названием главного экрана | Основная навигация использует «Главная» |
| Магазин начинался с большого промоблока | Сразу показаны баланс, категории, поиск и награды |
| «Выбрать» в товаре фактически открывало описание | Кнопка называется «Подробнее», покупка подтверждается в карточке товара |
| Длинные фильтры вытесняли таблицу на телефоне | На телефоне фильтры раскрываются кнопкой; место и баллы видны выше таблицы |

## Проверенные сценарии

На 1440, 1024 и 390 px проверены главная, коины, рейтинг, магазин и заказы. Дополнительно проверены фильтры рейтинга, поиск без пересчёта мест, смена периода, прямой переход в историю, отсутствие горизонтального растяжения страницы и текста о демонстрационном режиме.

Полный путь: сотрудник подаёт достижение → руководитель подтверждает → новые баллы меняют место в рейтинге → сотрудник подаёт на программу → HR подтверждает место. Покупка создаёт заказ и уменьшает коины, рейтинг сохраняется. Проверены каталог команд и поиск HR, коиновые формы, перезагрузка с сохранением заявок и заказов. Отдельный сценарий проверяет модальную форму весомой благодарности, веса 1/2, повтор с нулём новых баллов и сохранение истории.

Проверки кода: `npm run build`, `npm test` — 40 тестов, `git diff --check`. В тестах рейтинга зафиксированы одинаковые места при равных суммах, разделение ролей, период 12 месяцев и отсутствие изменений в балансах при построении таблицы. Снимки браузера — в игнорируемой папке `artifacts/`.
